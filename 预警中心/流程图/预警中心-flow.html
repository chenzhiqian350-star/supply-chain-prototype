预警中心 · 端到端业务流程

供应链协同平台 · 装柜计划模块 M06｜覆盖 15 类预警（ALT-T01～T15）的生成、去重、展示、跳转与处置闭环

1业务事件发生：预测未上传、QC 晚于装柜、CBM 超限 / 低装载、每日超限、SAP 出库差异、批次不可排、混装冲突等（15 类规则）
2系统按规则生成预警：种子预警 + 动态扫描（预测版本检查、按日柜数统计、柜内目的地集合、SAP 出库对账、空运批次登记）
3去重合并：同一「预警编号 + 业务对象」仅保留一条；同键多条时保留等级最高的一条，不重复堆叠
4预警中心列表展示：类型（编号）｜严重程度（高 / 中 / 低 / 动态）｜业务对象｜风险说明｜建议动作｜处理状态（未处理 / 暂不处理 / 已处理）
5SCM 筛选定位：按预警类型、严重程度、处理状态组合筛选后逐条处理；未处理数联动工作台「今日优先处理」与导航角标
查看按对象类型跳转到对应模块
货柜类 → 货柜编辑抽屉（排程视图）
批次类 → SKU 待分配批次池
预测类 → 需求预测
主数据类 → 主数据维护
分支处置确认弹窗：「是否将该预警标记为已处理？」
确认状态 → 已处理
取消弹出「请输入暂不处理原因」
原因为空提示「暂不处理必须填写原因」，不落库
原因已填 → 状态 = 暂不处理 + 原因留痕
6留痕与联动：处理动作写入操作日志（对象 / 编号 / 原因）；刷新列表与待处理计数；同一对象同一规则不重复产生
铁律：预警只提示和留痕，不自动取消货柜、不改写数量。需要阻断的规则（如跨客户 / 跨目的地混装、CBM 超限发布、每日上限）在具体业务操作点直接阻断；CBM 利用率不高于 85% 经 SCM 人工确认后允许发布且不再提示。
处理步骤 分支 / 确认 阻断 / 原因必填 闭环 / 留痕
