# 沟通记录 · 预警中心

## 需求确认（已确认决策）
- 预警中心集中处理 **15 类已业务确认的预警（ALT-T01～T15）**，口径与《预警类型与案例确认清单》V1.1（2026-09-02）对齐：11 类确认采用、4 类修改后采用（T01 / T06 / T07 / T13）。
- **只提示不干预**：预警只提示和留痕，不自动取消货柜、不改写数量、不静默排除批次；需要阻断的规则在具体业务操作点直接阻断（跨客户 / 跨目的地上架、CBM 超限发布、每日上限改期）。
- **去重**：以「预警编号 + 业务对象」为去重键，同键仅保留等级最高一条，不重复堆叠。
- **跳转**：每条预警必须能回到对应货柜、批次、SKU 或主数据——货柜 → 编辑抽屉，批次 → 批次池，预测 → 需求预测，其余 → 主数据维护。
- **处置闭环**：二选一——确认「已处理」；或「暂不处理」且**原因必填**（为空不落库）。全部动作写入操作日志。
- **等级**：高 / 中 / 低 / 动态四档；高=当日处理必要时阻断，中=计划确认或装柜前处理，低=观察，动态=显示升级原因和剩余时间。
- **例外确认**：CBM ≤ 85% 低装载经 SCM 人工确认后允许发布且不再提示；空运（ALT-T13）默认不主动弹窗、仅列表登记；预测未上传（ALT-T01）仅强提醒不阻断。
