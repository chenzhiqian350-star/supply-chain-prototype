需求背景

排程视图是 SCM 计划员在装柜计划里「把货柜排到具体日期与时段」的核心工作台。原流程中排程调整分散在不同入口，缺少统一的三视图视角与未保存调整管理。当前需收敛四点：月/周/日三视图各司其职（日视图处理执行与 QC 风险，周视图核对排柜顺序，月视图跨周拖动改期）；每日装柜数量受上限约束（默认 5 柜，可配置）；所有排程调整统一进入未保存状态，支持撤销与批量保存；日期链按香港工作天顺推，PV/CV 特殊批次默认加 3 个工作日。

视图层之外，货柜的高频编辑动作（改日期、上下架批次、拆批、替换、明细导出）收敛在「货柜编辑抽屉」完成。核心原则：装柜数量不能直接输入，只能通过上架、拆批、替换和下架改变；跨客户、跨目的地混装在操作点直接阻断，而非事后预警。

需求目标

  • 提供月 / 周 / 日三视图，默认进入日视图，视图间可快速切换。
  • 月视图支持跨周拖动货柜改期，周末不排柜；周视图按「时间段 × 工作日」矩阵核对排柜顺序。
  • 每日装柜数量受上限约束，超限的日期在月视图中标识并阻止改期落位。
  • 拖拽、改期等调整统一进入未保存状态，支持撤销与批量保存。
  • 货柜日期链按「最晚 QC → 装柜 → ETD → ETA → T0」顺推，香港工作天，PV/CV +3 工作日。
  • 点击日视图货柜卡片进入货柜编辑抽屉，完成上下架、拆批、替换、执行信息维护与明细导出。
  • 上架仅允许同客户、同目的地批次；跨客户、跨目的地在操作点硬阻断。
  • 货柜按「计划中 → 执行中 → 已完成 / 已取消」生命周期流转，计划结构字段随装柜日闸门锁定，按角色控制可编辑范围。

装柜排程 视图切换

【页面元素】顶部工具栏含「月视图 / 周视图 / 日视图」三个 Tab（默认日视图）；月视图显示「‹ 2026年9月 ›」周期切换器，周视图显示「‹ 第36周 ›」，日视图显示「前一天 / 09/01 周二 / 后一天」切换器；右侧为「撤销未保存」「批量保存」按钮。

【交互说明】点月/周/日 Tab → 对应视图显示，周期切换器随视图联动显隐；月视图用 ‹› 按月翻页，周视图按周翻页，日视图按天翻页。

【功能逻辑】三视图共用同一份货柜数据，切换仅改变展示维度；日视图为唯一提供货柜编辑入口的视图，月/周视图用于浏览与拖动。

【数据与内容规则】日期范围覆盖当月起 30 天；时段固定为 09:00-10:30、10:30-12:00、13:00-14:30、14:30-16:00、16:00-17:30。
日视图

【页面元素】按时段纵向列出当日各时段的货柜卡片；货柜卡片展示货柜编号、客户、目的地、运输方式、SKU 数量、CBM、QC 摘要与预计 T0。

【交互说明】点击货柜卡片 → 打开货柜编辑抽屉；前后一天切换 → 刷新当日时段列表与工作台。

【功能逻辑】日视图是 SCM 处理货柜的主入口，用于查看执行情况与 QC 风险；QC 未完成或晚于装柜的货柜以预警标识提示。

【边界说明】某时段无货柜时显示「空时段」占位；周末日期不排柜。
周视图

【页面元素】「时间段 × 工作日」矩阵：首列为时段，其余列为周一至周五（共 5 个工作日），交叉单元格放置对应日期与时段的货柜。

【交互说明】拖拽货柜到目标日期/时段单元格 → 完成改期；按周翻页查看不同周的排柜。

【功能逻辑】周视图用于核对排柜顺序与负载分布，不提供货柜编辑入口；拖动同样进入未保存状态。

【数据与内容规则】工作日以周一至周五为列；周末不显示在周矩阵中。
月视图（跨周拖动）

【页面元素】月历网格：每个日期格显示「日期 + 星期 + 已排数/上限」，下方放置当日货柜卡片；周末格有「周末不排柜」占位。

【交互说明】拖拽货柜卡片到目标日期格 → 跨周改期；拖到周末格不响应；超限日期格以红框标识。

【功能逻辑】月视图用于跨周调整装柜节奏；日期格头部实时显示「已排货柜数/每日上限」，超过上限显示超限样式。

【边界说明】月视图为浏览与拖动视图，不提供货柜内容编辑；空日期格显示「可放置货柜」。
拖拽改期与每日上限

【功能逻辑】拖拽落位时写入新日期/时段并标记未保存；改期后校验每日装柜上限（默认 5 柜），超过则提示「当日已排 N 柜，超过每日上限 5 柜，请改期或申请扩容」。

【边界说明】周末落位被阻止；无权限（非 SCM 计划员或计划已锁定）时拖拽不响应并提示。

【前置条件与权限】每日上限由装柜日程主数据配置，默认 5 柜，修改后对后续排程生效。
未保存调整管理

【页面元素】存在未保存调整时顶部显示「你有 N 项未保存调整」提示条，含「撤销」「批量保存」按钮。

【交互说明】点「批量保存」→ 校验每日上限、CBM、QC 完成时间与工作日规则后落库；点「撤销」→ 回退未保存调整。

【功能逻辑】所有排程调整统一进入未保存状态，保存前不写入正式计划；保存时逐项校验，命中异常时给出对应提示。

【文案规范】「撤销未保存」「批量保存」「你有 N 项未保存调整」为统一提示文案。
当日编辑

【编辑链路】日切换（前一天/后一天）定位目标日期 → 时段内点击货柜卡片 → 打开货柜编辑抽屉 → 在抽屉内完成调整日期、上下架、拆批、替换、执行信息维护 → 关闭抽屉 → 工具栏「批量保存」统一落库。

【页面元素】日视图时段卡片含：货柜编号、客户 · 目的地 · 运输方式 · 柜型、生命周期标签（计划中/执行中/已完成/已取消）、SKU 摘要、三个日期芯片（检验完成日期 / 装柜日期 / T0 到达日期）、CBM 利用率进度条。

【功能逻辑】当日编辑入口收敛在日视图（点击卡片进抽屉）与月/周视图（拖拽改期）两条路径；月/周视图不提供货柜内容编辑入口。所有编辑动作（拖拽、改期、上下架、拆批、替换）统一进入未保存状态，由「批量保存」统一校验落库。

【前置条件与权限】仅 SCM 计划员 / SCM 主管可编辑计划内容；已执行或已取消的货柜不可编辑；已到装柜日（闸门关闭）的货柜需 SCM 主管「授权变更」后方可编辑。
上架 / 下架 / 替换

【页面元素】抽屉操作栏「上架批次 / 替换 / 下架」三个入口。「上架批次 / 替换」打开「可用批次池」弹窗：搜索框（SKU / 批次号 / 品名 / 目的地模糊搜索）、状态筛选（默认「可排」）、客户筛选、SKU 筛选、「显示跨目的地批次（仅查看，不可上架）」勾选框、分页控件；池表格列：批次号、SKU / 产品名称（带优先级标签）、客户、目的地、数量、箱数、CBM（带风险标签）、QC、状态、操作（上架 / 禁止上架）。

【交互说明】上架 → 从批次池点「上架」将批次加入当前货柜；替换 → 先在抽屉 SKU 明细中单选柜内批次，再从批次池选择可上架批次按位替换；下架 → 在抽屉 SKU 明细中单选批次 → 点「下架」→ 二次确认后批次回到批次池。

【排序规则】批次池按「同目的地优先，其次同 SKU 优先」排序；优先级标签：同 SKU、同目的地混装、不同客户·禁止同柜、不同目的地·禁止同柜；风险标签：人工改运（空运）、不同客户·禁止同柜、不同目的地·禁止同柜、尾箱不足50%、CBM偏高、可上架。

【数据与内容规则】上架成功后批次状态置为「已分配」，货柜重算 CBM 并刷新排程 / 报表 / 执行表；下架、替换、取消货柜后原批次状态一律回「可排」回到待分配批次池；跨目的地批次默认不展示，勾选后仅查看、按钮置灰「禁止上架」。

【文案规范】阻断提示「不同客户，不能放置统一货柜」「不同目的地不允许同柜，请拆为两个货柜」；下架确认「确认下架批次 X？下架后数量会回到批次池。」；成功提示「已下架，回到待分配批次池」。
拆批

【页面元素】「拆分批次」弹窗：拆出箱数（默认带出系统建议值）、对应产品数量（按件装量自动换算、只读）、调整原因（选填）、剩余量提示条、「取消 / 确认拆分」按钮。

【交互说明】在抽屉 SKU 明细单选批次 → 点「拆批」或在批次池点「拆分批次」→ 输入拆出箱数（整箱为最小单位）→ 确认拆分 → 拆出数量回到批次池，剩余量留在当前货柜。

【功能逻辑】仅「可排」状态批次可拆批（单 SKU 单批次）；拆出数量必须大于 0 且小于批次剩余数量；CBM 超限时系统按「最少整箱移出」给出建议拆出箱数并显示预计释放的 CBM；拆出记录沿用原 SAP 批号（批号不变，以内部拆分序号追溯），状态回「可排」并标注「可排·人工拆批」；拆批后 CBM 按数量比例重算并刷新达成率与预警。

【文案规范】「请先选择一个可拆分批次」「仅可对可排批次执行单 SKU 拆批」「拆分数量必须大于 0 且小于剩余数量」。
明细预览与下载

【页面元素】「装柜明细预览」弹窗：标题（货柜编号）、说明文案（随计划实时生成，可随时预览、下载与打印，用于线下仓库按执行表单独装柜）、26 列装柜明细表格（货柜编号、计划装柜日期、产品编码、中文货名、批次号、拆分标识、拆分序号、出货数量、运输方式（SAP）、每件 CBM、件装量、箱数、每批 CBM 等，可横向滚动）、底部「下载 Excel」「打印」按钮。

【交互说明】点「预览明细」→ 实时展示当前货柜装柜明细；点「下载明细」→ 生成《装柜执行表》Excel 文件（14 列中文表头：货柜编号、计划装柜日期、产品编码、中文货名、批次号、拆分标识、拆分序号、出货数量、箱数、每批 CBM、客户、目的地、货柜名称、计划 T0 入库日期）。

【功能逻辑】明细与计划数据实时同步，不生成静态副本；浏览器 Excel 组件未加载时自动降级生成带 BOM 的 CSV 备用文件；预览与下载动作均写入货柜操作日志留痕。

货柜详情抽屉

点击日视图货柜卡片打开「货柜编辑抽屉」，从上到下五个区域：① 状态栏（QC 最晚完成 / 计划装柜 / CBM 利用率与预计 T0）；② 装柜产品 SKU 明细（含操作栏）；③ 货柜与执行信息；④ 货柜时间轴（计划路径：最晚 QC → 计划装柜日 → 计划离港日 → 计划到港日 → T0 入库日期）；⑤ 操作日志。抽屉标题即货柜名称，点击可直接修改，保存后生效。

上下架业务规则

规则类型规则提示 / 处理文案
允许上架同客户且同目的地的「可排」状态批次按钮「上架」可点
排序优先同目的地优先（权重 10），其次同 SKU 优先（权重 1）标签「同 SKU」「同目的地混装」
硬阻断 ①不同客户批次禁止同柜「不同客户，不能放置统一货柜」
硬阻断 ②不同目的地批次禁止同柜「不同目的地不允许同柜，请拆为两个货柜」
仅查看跨目的地批次默认不展示；勾选「显示跨目的地批次」后可见但不可上架按钮置灰「禁止上架」
风险提示（不阻断）尾箱不足 50%、单批 CBM 偏高（>18）、空运批次标签「尾箱不足50%」「CBM偏高」「人工改运」
回池规则 ①下架：批次状态回「可排」，从货柜移除「已下架，回到待分配批次池」
回池规则 ②替换：新批次「已分配」入柜，被替换批次回「可排」「批次 X 已替换到当前货柜」
回池规则 ③取消货柜：柜内全部批次回「可排」，货柜移除「货柜已取消，柜内批次已回到待分配批次池」
数量不可直改装柜数量不能直接输入，只能通过上架、拆批、替换、下架四条路径改变—

异常与边界

场景处理
周末落位月视图周末格禁止拖放，提示「周末不排柜」
每日装柜超限月视图超限日期格标识；改期落位校验并阻止，提示改期或申请扩容
无权限调整非 SCM 计划员或计划已锁定，拖拽不响应并提示「当前角色不可调整计划内容，或需装柜日后授权变更」
空时段 / 空日期日视图显示「空时段」，月视图显示「可放置货柜」
QC 未完成或晚于装柜货柜卡片以预警标识提示，不自动修改计划
不同客户 / 不同目的地同柜上架操作点硬阻断，提示「不同客户，不能放置统一货柜」/「不同目的地不允许同柜，请拆为两个货柜」
下架未选批次提示「请选择货柜内批次后再下架」
拆批数量非法提示「拆分数量必须大于 0 且小于剩余数量」；非可排批次提示「仅可对可排批次执行单 SKU 拆批」
调整日期非法不在排程范围提示按 MM/DD 格式重输；周末提示「周末默认不排柜，请选择工作日」；超每日上限提示「当日已排 N 柜，超过每日上限 X 柜，请改期或申请扩容」；周频冲突提示与冲突货柜编号
CBM 超限发布阻断「发布执行表快照」；超限时拆批弹窗给出最少整箱移出建议
低装载（CBM ≤ 85%）需 SCM 人工「确认低装载」后方可发布，确认后不再重复提示
已取消货柜全部字段与操作按钮禁用
