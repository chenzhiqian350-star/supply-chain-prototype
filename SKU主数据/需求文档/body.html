需求背景

SKU 主数据是需求预测、自动预排与日期链计算的共同数据基准。产品编码、客户、目的地、件装量、每件 CBM、各阶段周期等字段一旦缺失或错误，会直接导致预排失败、CBM 计算偏差和 T0 推算失真。

此前主数据字段分散在多个来源系统（SAP、排程系统、线下手工表），维护入口不统一，且缺少「字段来源」与「缺失影响」的显式说明，导致 SCM 难以判断某个字段该在哪里改、改了会影响什么。本模块需要收敛为单一结构化弹窗维护全部 27 个字段，并明确每类字段的来源、可维护角色与变化影响范围。

核心原则：主数据变化不追溯修改已有计划。字段变更只影响后续预排与后续调整，对未执行货柜如需复核则由「主数据变更影响」预警提示 SCM 处理。

需求目标

  • 提供 SKU 主数据列表，支持按产品编码关键字、目的地、运输方式查询。
  • 新增与维护全部通过结构化弹窗完成，一次维护全部 27 个字段，分为四个分组。
  • 字段列表显式标注来源（SAP 获取 / 人手维护 / 产品主数据 / 排程系统），便于判断维护入口。
  • 四类柜型（40'RF / 40'HQ / 20'RF / 20'GP）的产品 CBM 上限按「SKU × 柜型」在本页直接维护；货柜校验取柜内所有 SKU 上限的 MIN。
  • 产品编码必填且唯一；缺失件装量、目的地或周期的 SKU 不参与自动预排。
  • 支持停用 SKU：停用后不参与后续预排，但保留历史计划与操作日志；非 GMP SKU 停用需二次确认。
  • 目的地或默认运输方式变更影响未执行计划时，生成「主数据变更影响」预警，由 SCM 复核。
  • 提供「同步 SAP」入口：一键从 SAP 产品主数据接口拉取最新字段值，刷新列表中的 SAP 来源字段。
  • 提供「下载模板」入口（位于「导入主数据」左侧）：下载标准 CSV 导入模板，供离线填报后批量导入。
  • 查询区在原有产品编码关键字之外，新增「SPU」查询条件，支持按 SPU 定位同一系列下的全部产品编码。

详细方案

一级模块二级功能原型描述
产品 SKU 主数据 查询区

【页面元素】查询区含：SPU 搜索框（新增，支持模糊匹配，如「SPU-0182」）、产品编码搜索框（支持关键字模糊匹配）、目的地下拉、运输方式下拉、「查询」按钮。

【交互说明】输入或选择条件后点「查询」→ 列表刷新；条件可叠加（AND）；清空条件后重新展示全部启用与停用记录。

【功能逻辑】查询仅过滤展示，不改变数据；默认展示全部记录并按产品编码升序排列。SPU 与产品编码两个关键字条件、目的地与运输方式两个下拉条件之间均为叠加关系（AND）。

【数据与内容规则】目的地、运输方式选项来源于已维护的 SKU 主数据聚合值；SPU 与产品编码为文本关键字，大小写不敏感。
SKU 列表

【页面元素】列表上方工具栏含四个操作：「同步 SAP」「下载模板」「导入主数据」「新增 SKU」（「下载模板」固定位于「导入主数据」左侧）。列表展示产品编码、产品名称、客户、目的地、运输方式、规模属性、生产区域、GMP 状态与启用状态，行尾提供「编辑」「停用 / 启用」入口。

【交互说明】点「编辑」→ 打开 27 字段弹窗并带入当前值；点「停用」→ 二次确认后停用；点「启用」→ 恢复参与预排。

【功能逻辑】停用记录仍在列表中可见（便于查历史），但状态列显示为「已停用」且不进入后续预排。
27 字段弹窗维护

【页面元素】结构化弹窗，按四个分组纵向排列 27 个字段：① 基本信息（8）；② 客户与物流（10）；③ 周期参数（天）（5）；④ 产品 CBM 上限（SKU × 柜型，4）。每个字段旁标注来源与必填性。

【交互说明】新增时弹窗为空表单；编辑时带入当前值；点「保存」→ 执行校验后落库；点「取消」→ 放弃变更并关闭。

【功能逻辑】一次性维护全部字段；批量导入为辅助手段，不能直接覆盖已排计划。

【前置条件与权限】产品编码必填且唯一；四类柜型下的产品 CBM 上限按「SKU × 柜型」在本页维护；货柜校验取柜内所有 SKU 上限的 MIN。
字段来源标注

【页面元素】列表与弹窗中，每个字段标注来源：从 SAP 获取、人手维护、产品主数据（SKU × 柜型）、排程系统。

【功能逻辑】来源标注明确该字段的数据责任方与维护入口，SCM 据此判断字段异常时应联系哪个系统或角色修正。

【数据与内容规则】「产品主数据」来源的字段以主数据维护值为准；「从 SAP 获取」的字段以 SAP 同步值为准，人工不可覆盖。
产品 CBM 上限（SKU × 柜型）

【功能逻辑】四类柜型下的产品 CBM 上限（40'RF / 40'HQ / 20'RF / 20'GP）按「SKU × 柜型」在本页维护；货柜校验取柜内所有 SKU 上限的 MIN。

【数据与内容规则】上限变更不追溯改写既有货柜，仅生成受影响计划预警。
同步 SAP 主数据

【页面元素】工具栏「同步 SAP」按钮（与「下载模板」「导入主数据」「新增 SKU」并列）。

【交互说明】点「同步 SAP」→ 以加载态拉取 SAP 产品主数据接口最新值；同步期间按钮置灰，完成后刷新列表并提示同步结果（新增 / 更新 / 无变化条数）。

【功能逻辑】同步为只读拉取，仅覆盖标注为「从 SAP 获取」的字段（如产品名称、剂型、件装量、每件 CBM、产品有效期、GMP 状态等）；人手维护字段不被覆盖；同步不追溯改写既有货柜计划，涉及未执行计划的变更按原规则生成「主数据变更影响」预警。

【前置条件与权限】仅 SCM 计划员 / SCM 主管可执行；同步为全量刷新，不支持按选中行同步。原型中该按钮为静态占位，实际以 SAP 产品主数据接口为准。

【文案规范】「同步 SAP 主数据：原型为静态占位，实际以 SAP 产品主数据接口为准」为统一提示文案。
下载导入模板

【页面元素】工具栏「下载模板」按钮，固定位于「导入主数据」左侧。

【交互说明】点「下载模板」→ 下载标准 CSV 模板文件，文件名「SKU主数据导入模板.csv」；模板首行为 27 字段的中文表头，带 UTF-8 BOM 以兼容 Excel 中文。

【功能逻辑】模板表头与「导入主数据」解析规则一一对应；用户按模板离线填报后可原样导入，避免因表头不一致导致导入失败。

【数据与内容规则】模板仅含表头行，不含示例数据行；字段顺序与页面 27 字段清单保持一致。
启用 / 停用与变更预警

【交互说明】停用 → 二次确认（非 GMP SKU 停用需确认）后生效，写入操作日志「停用非 GMP SKU」；启用 → 恢复参与后续预排。

【功能逻辑】停用后不参与后续预排，保留历史计划与操作日志；目的地或默认运输方式变更影响未执行计划时，生成「主数据变更影响」预警。

【边界说明】主数据变化不自动改写未执行货柜，仅产生受影响计划预警，由 SCM 复核处理。

字段口径与计算规则

项目口径
箱数ceil(产品数量 / 件装量)
批次 CBM箱数 × 每件 CBM
有效业务组合SKU + 客户 + 目的地；需求预测按产品编码对应主数据带出客户与目的地

参与自动预排的前置条件启用状态、件装量完整、目的地完整、周期参数完整

异常与边界

场景处理
产品编码为空或重复阻止保存，提示编码必填且唯一
缺少件装量 / 目的地 / 周期允许保存，但该 SKU 不参与自动预排并给出提示
SKU 被选入新增预测行只带出启用且组合有效的记录；主数据组合不匹配时预测行校验不通过
停用 SKU不参与后续预排，保留历史计划与日志；非 GMP SKU 停用需二次确认
目的地或运输方式变更影响未执行计划时生成「主数据变更影响」预警，由 SCM 复核；不自动改写货柜
CBM 上限调整按 SKU × 柜型 在本页维护；变更不追溯改写既有货柜，仅生成受影响计划预警
批量导入作为辅助手段，不能直接覆盖已排计划
