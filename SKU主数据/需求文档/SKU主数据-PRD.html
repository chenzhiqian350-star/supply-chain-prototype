需求背景

SKU 主数据是需求预测、自动预排与日期链计算的共同数据基准。产品编码、客户、目的地、件装量、每件 CBM、各阶段周期等字段一旦缺失或错误，会直接导致预排失败、CBM 计算偏差和 T0 推算失真。

此前主数据字段分散在多个来源系统（SAP、排程系统、线下手工表），维护入口不统一，且缺少「字段来源」与「缺失影响」的显式说明，导致 SCM 难以判断某个字段该在哪里改、改了会影响什么。本模块需要收敛为单一结构化弹窗维护全部 27 个字段，并明确每类字段的来源、可维护角色与变化影响范围。

核心原则：主数据变化不追溯修改已有计划。字段变更只影响后续预排与后续调整，对未执行货柜如需复核则由「主数据变更影响」预警提示 SCM 处理。

需求目标

  • 提供 SKU 主数据列表，支持按产品编码关键字、目的地、运输方式查询。
  • 新增与维护全部通过结构化弹窗完成，一次维护全部 27 个字段，分为四个分组。
  • 字段列表显式标注来源（SAP 获取 / 人手维护 / 继承货柜类型主数据 / 排程系统），便于判断维护入口。
  • 四类柜型（40'RF / 40'HQ / 20'RF / 20'GP）CBM 上限展示为继承值，不在此页直接维护，用于导入校验。
  • 产品编码必填且唯一；缺失件装量、目的地或周期的 SKU 不参与自动预排。
  • 支持停用 SKU：停用后不参与后续预排，但保留历史计划与操作日志；非 GMP SKU 停用需二次确认。
  • 目的地或默认运输方式变更影响未执行计划时，生成「主数据变更影响」预警，由 SCM 复核。

详细方案

一级模块二级功能原型描述
产品 SKU 主数据 查询区

【页面元素】查询区含：产品编码搜索框（支持关键字模糊匹配）、目的地下拉、运输方式下拉、「查询」按钮。

【交互说明】输入或选择条件后点「查询」→ 列表刷新；条件可叠加（AND）；清空条件后重新展示全部启用与停用记录。

【功能逻辑】查询仅过滤展示，不改变数据；默认展示全部记录并按产品编码升序排列。

【数据与内容规则】目的地、运输方式选项来源于已维护的 SKU 主数据聚合值。
SKU 列表

【页面元素】列表展示产品编码、产品名称、客户、目的地、运输方式、规模属性、生产区域、GMP 状态与启用状态，行尾提供「编辑」「停用 / 启用」入口。

【交互说明】点「编辑」→ 打开 27 字段弹窗并带入当前值；点「停用」→ 二次确认后停用；点「启用」→ 恢复参与预排。

【功能逻辑】停用记录仍在列表中可见（便于查历史），但状态列显示为「已停用」且不进入后续预排。
27 字段弹窗维护

【页面元素】结构化弹窗，按四个分组纵向排列 27 个字段：① 基本信息（8）；② 客户与物流（10）；③ 周期参数（天）（5）；④ 柜型 CBM 上限（4）。每个字段旁标注来源与必填性。

【交互说明】新增时弹窗为空表单；编辑时带入当前值；点「保存」→ 执行校验后落库；点「取消」→ 放弃变更并关闭。

【功能逻辑】一次性维护全部字段；批量导入为辅助手段，不能直接覆盖已排计划。

【前置条件与权限】产品编码必填且唯一；四类柜型 CBM 上限为继承值（只读展示），维护入口在货柜类型主数据。
字段来源标注

【页面元素】列表与弹窗中，每个字段标注来源：从 SAP 获取、人手维护、继承货柜类型主数据、排程系统。

【功能逻辑】来源标注明确该字段的数据责任方与维护入口，SCM 据此判断字段异常时应联系哪个系统或角色修正。

【数据与内容规则】「继承货柜类型主数据」的字段在本页只读；「从 SAP 获取」的字段以 SAP 同步值为准，人工不可覆盖。
柜型 CBM 上限继承

【功能逻辑】四类柜型容量（40'RF / 40'HQ / 20'RF / 20'GP）展示为本 SKU 的继承值，用于导入校验与柜型选择；容量本身只能在货柜类型主数据中维护。

【数据与内容规则】继承值随货柜类型主数据的变更而更新，本页不提供直接编辑。
启用 / 停用与变更预警

【交互说明】停用 → 二次确认（非 GMP SKU 停用需确认）后生效，写入操作日志「停用非 GMP SKU」；启用 → 恢复参与后续预排。

【功能逻辑】停用后不参与后续预排，保留历史计划与操作日志；目的地或默认运输方式变更影响未执行计划时，生成「主数据变更影响」预警。

【边界说明】主数据变化不自动改写未执行货柜，仅产生受影响计划预警，由 SCM 复核处理。

字段口径与计算规则

项目口径
箱数ceil(产品数量 / 件装量)
批次 CBM箱数 × 每件 CBM
有效业务组合SKU + 客户 + 目的地；需求预测按产品编码对应主数据带出客户与目的地
日期链最晚 QC → 计划装柜 → ETD → ETA → T0；检验 / 装柜按香港工作天，离港 / 运输按自然天，T0 按内地工作天
参与自动预排的前置条件启用状态、件装量完整、目的地完整、周期参数完整

异常与边界

场景处理
产品编码为空或重复阻止保存，提示编码必填且唯一
缺少件装量 / 目的地 / 周期允许保存，但该 SKU 不参与自动预排并给出提示
SKU 被选入新增预测行只带出启用且组合有效的记录；主数据组合不匹配时预测行校验不通过
停用 SKU不参与后续预排，保留历史计划与日志；非 GMP SKU 停用需二次确认
目的地或运输方式变更影响未执行计划时生成「主数据变更影响」预警，由 SCM 复核；不自动改写货柜
柜型容量调整本页只读继承；调整入口在货柜类型主数据，变更后继承值同步更新
批量导入作为辅助手段，不能直接覆盖已排计划
