# 沟通记录 · 产品 SKU 主数据

## 需求确认（已确认决策）
- **单一结构化弹窗维护全部 27 个字段**，分四组：① 基本信息（8）② 客户与物流（10）③ 周期参数-天（5）④ 柜型 CBM 上限（4，继承值只读）。
- **字段来源显式标注**：从 SAP 获取 / 人手维护 / 继承货柜类型主数据 / 排程系统；便于判断字段异常时的维护入口与责任方。
- **四类柜型 CBM 上限**（40'RF / 40'HQ / 20'RF / 20'GP）展示为继承值，本页只读，维护入口在货柜类型主数据，用于导入校验。
- **保存校验**：产品编码必填且唯一；缺少件装量、目的地或周期的 SKU 允许保存但**不参与自动预排**并提示。
- **有效业务组合**：SKU + 客户 + 目的地三者缺一不可参与预测与预排；新增预测行只带出启用且组合有效的记录。
- **启用 / 停用**：停用后不参与后续预排，**保留历史计划与操作日志**；非 GMP SKU 停用需二次确认并写入日志。
- **变更不追溯**：主数据变化**不自动改写未执行货柜**；目的地或默认运输方式变更影响未执行计划时生成「主数据变更影响」预警，由 SCM 复核。
- **批量导入**：作为辅助手段，不能直接覆盖已排计划。

## 字段口径引用
- 箱数 = `ceil(产品数量 / 件装量)`；批次 CBM = `箱数 × 每件 CBM`。
- 日期链：最晚 QC → 计划装柜 → ETD → ETA → T0；检验 / 装柜按香港工作天，离港 / 运输按自然天，T0 按内地工作天。
- 参与自动预排前置条件：启用状态 + 件装量 + 目的地 + 周期参数四项完整。
