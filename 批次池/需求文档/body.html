需求背景

批次池汇集排程系统与 SAP 的可用批次，是自动预排、拆批回池与货柜上架共用的唯一待分配数据源。此前批次「能否参加排柜」「还剩多少可排」两个问题分散在不同页面与线下表格中，容易出现同一批次被重复排入多个货柜、或已排量口径不一致导致缺口误判。

本模块需要收敛三点：批次处于预排阶段，库存可用性以「SAP 状态」（非限制 / 冻结）显式表征，不让批次静默消失；剩余可用量必须有单一、可复算的口径，并对 SAP 出库与销毁做校正；批次数据以排程同步与 SAP 回传为准，人工只做拆批与排除，不直接改数量。

需求目标

  • 以表格形式汇集全部批次（预排阶段不做可排 / 不可排分栏），支持分页浏览。
  • 明确每个批次的剩余可用量口径：剩余量 = 原始可用量 − max(已排计划量, SAP 出库量) − SAP 销毁量。
  • 支持按产品编码（多选可搜索）、生产月份、SAP 状态（全部 / 非限制 / 冻结）筛选，并保留整柜与同步排程操作。
  • 支持「同步 SAP 状态」：一键拉取 SAP 回传的批次库存状态（非限制 / 冻结）并刷新列表。
  • 批次表按计划 / 实际双口径展示生产与 QC 日期：排程计划生产日期、排程实际日期、QC 计划完成日期、QC 实际完成日期；实际值列以「实际」标识样式与计划值区分，供开发与业务识别。
  • 批次表不再设「状态」列；「SAP 状态」（非限制 / 冻结）为该表唯一的状态类字段。
  • 拆批统一在装柜视图处理；本模块不再提供拆分批次按钮。
  • 批次在预排阶段不再单独区分「可排 / 不可排」；库存可用性由「SAP 状态」（非限制 / 冻结）表征，冻结批次不参加自动预排并展示原因。
  • SAP 销毁或库存差异影响已排批次时，生成批次不足 / SAP 对账差异预警，不自动改写货柜。
  • 上架不同客户或不同目的地批次一律硬阻断，不生成后续混装预警。

详细方案

一级模块二级功能原型描述
批次池 批次列表（全量）

【页面元素】预排阶段不再设「可排 / 不可排」页签，页面统一展示全部批次；筛选区与操作按钮位于表格上方。

【交互说明】列表按当前筛选条件展示全部批次；库存可用性由「SAP 状态」列体现（非限制 / 冻结），冻结批次行以红标签提示。

【功能逻辑】「SAP 状态」为预排阶段唯一的可用性判定维度：冻结批次不参加自动预排；排程数据与 QC 节点仅影响自动预排的命中，不再单独成列展示可排性。

【边界说明】冻结批次保留在列表中并展示原因，不允许静默排除；其可用性恢复到「非限制」后自动恢复参排。
筛选与操作区

【页面元素】筛选区含：产品编码多选筛选（支持输入关键字搜索）、生产月份筛选（下拉）、SAP 状态筛选（下拉：全部 / 非限制 / 冻结）；操作按钮含「整柜」「同步排程」「同步 SAP 状态」。

【交互说明】产品编码多选 → 输入关键字实时过滤下拉选项，可多选叠加；SAP 状态筛选 → 按 SAP 回传的库存状态过滤（非限制 / 冻结）；点「同步排程」→ 拉取最新排程批次并刷新列表；点「同步 SAP 状态」→ 拉取 SAP 回传的最新批次库存状态并刷新「SAP 状态」；点「整柜」→ 将当前筛选范围内可用批次（非限制）按预排规则整柜归集。

【功能逻辑】筛选条件为叠加关系（AND）；产品编码多选支持模糊匹配；筛选结果与分页联动。

【数据与内容规则】生产月份选项来源于当前数据范围内批次的实际生产月份；SAP 状态选项固定为「全部 / 非限制 / 冻结」三档，取值来自 SAP 回传，人工不可直接修改。
批次表（13 列）

【页面元素】13 列：选择框、产品编码、产品名称、批次号、剩余数量、件装量、箱数、每批 CBM、排程计划生产日期、排程实际日期、QC 计划完成日期、QC 实际完成日期、SAP 状态。已移除「目的地」「排程状态」「状态」三列；原「排程完成日期」「QC 完成（预测）」两列拆分为四列（计划 / 实际各两列）。表格支持横向滚动与分页。

【交互说明】点列头 → 按该列排序；点击批次号 → 展开该批次详情（含原始可用量、已排量、剩余量明细）。

【实际值标识】「排程实际日期」「QC 实际完成日期」两列由系统回传后展示，并在数值旁加注「实际」标识（浅蓝胶囊样式）；未回传时分别显示「待排程回传」「待 QC 回传」。计划口径两列（排程计划生产日期、QC 计划完成日期）为浅色常规文本，实际值列以加粗 + 标识与计划值区分。

【SAP 状态列】批次表唯一的状态类字段，展示该批次在 SAP 中的库存状态：非限制（绿标签）/ 冻结（红标签）；来源为 SAP 回传，人工不可修改。原「状态」（可排 / 不可排）列已移除——预排阶段不再单独判定可排性，库存可用性统一以本列表征；冻结批次不参加自动预排。

【数据与内容规则】箱数 = ceil(产品数量 / 件装量)；每批 CBM = 箱数 × 每件 CBM；剩余数量字段按下方专章口径计算。

【排序规则】默认按「非限制优先 → 同客户 → 同 SKU → 剩余数量降序」排列。
整柜归集

【交互说明】点「整柜」→ 在当前筛选范围内按 SKU + 客户 + 目的地分组，将可排批次按 CBM 上限归集为整柜建议，给出每组建议货柜数与装载率。

【功能逻辑】归集仅使用 SAP 状态为「非限制」且 QC 可满足的批次；容量上限按 SKU × 柜型 取柜内所有 SKU 上限的 MIN；超过上限时拆分为多柜。

【边界说明】整柜归集为建议，需 SCM 确认后才生成货柜；不同客户、不同目的地的批次不合并归集。
同步排程

【交互说明】点「同步排程」→ 拉取最新排程批次数据，刷新排程日期与剩余数量；同步过程中按钮置为加载态。

【功能逻辑】批次数据以排程同步结果为准；同步后受影响货柜的 CBM、达成率与预警联动重算。

【边界说明】同步为只读拉取，不自动改写货柜计划；出现差异时转为预警条目。
同步 SAP 状态

【页面元素】操作区「同步 SAP 状态」按钮（与「整柜」「同步排程」并列）；筛选项「SAP 状态」下拉。

【交互说明】点「同步 SAP 状态」→ 以加载态拉取 SAP 回传的批次库存状态；同步期间按钮置灰，完成后刷新列表并提示（状态变化条数）。

【功能逻辑】批次 SAP 状态取值固定三档：非限制（可正常参与排柜）、冻结（不参加自动预排并展示原因）、全部（筛选口径，不参与判定）。状态以 SAP 回传为准，人工不可直接修改；状态由非限制变为冻结时，若该批次已排入未执行货柜，生成「批次不可排 / 状态异常」预警。

【边界说明】同步为只读拉取，不自动改写货柜计划；差异转为预警条目。功能为开发实现项，原型中为静态占位。
批次不足 / 对账差异预警

【功能逻辑】SAP 销毁或库存差异导致已排批次的可用量不足以覆盖已排计划量时，生成「批次不足」或「SAP 对账差异」预警；QC 未满足时生成 QC 类预警。

【边界说明】预警只提示与留痕，不自动取消货柜、不自动改写数量；需要阻断的规则在具体操作点（上架 / 拆批 / 保存）直接阻断。

【前置条件与权限】预警生成后由 SCM 复核处理；处理动作写入操作日志。

剩余可用量计算口径（专章）

批次剩余可用量是本模块的核心口径，也是预排、上架、达成率与缺口计算的共同基准。为保证可复算、可对账，统一采用以下公式：

项目口径数据来源
原始可用量该 SAP 批号下的原始可用数量（生产入库后的可分配总量）排程系统 / SAP
已排计划量当前所有未取消货柜中该批次被分配的合计量装柜计划
SAP 出库量该批次已实际出库的数量（发运后回传）SAP
SAP 销毁量该批次已确认销毁的数量SAP
剩余可用量原始可用量 − max(已排计划量, SAP 出库量) − SAP 销毁量系统计算

口径说明：

  • 已排计划量与 SAP 出库量取 max，而非相加——因为发运后两者描述的是同一批货的两种视角（计划分配 vs 实际出库），相加会重复扣减。
  • SAP 销毁量为独立扣减项，与出库互斥，不参与 max 比较。
  • 计算结果小于 0 时按 0 处理，并触发「SAP 对账差异」预警。
  • 批次整体分配守恒：剩余可用量 + 已排计划量 + SAP 销毁量 = 原始可用量（当已排计划量 ≥ SAP 出库量时成立）。

数值算例

场景原始可用量已排计划量SAP 出库量SAP 销毁量剩余可用量说明

拆批与守恒（统一在装柜视图处理）

批次池不再提供「拆分批次」按钮，拆批统一在装柜视图 → 货柜编辑抽屉中按柜内批次执行；下表规则同适用于装柜视图的拆批操作。

规则说明
批号不变拆出的子记录沿用原 SAP 批号，不生成新批号；以「拆分标识 + 拆分序号」追溯
最小单位整箱为最小调整单位，拆出量按整箱计
总分配量守恒拆批前后：剩余量 + 拆出量 = 拆批前的剩余量
回池状态拆出部分标注「人工拆批」回到待分配批次池，库存可用性沿用其 SAP 状态
