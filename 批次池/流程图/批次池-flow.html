批次池 · 端到端业务流程

供应链协同平台 · 装柜计划模块 M04｜从批次同步到可排判定、剩余量计算、人工拆批与预警生成的待分配闭环

1批次数据同步：从排程系统与 SAP 拉取批次号、原始可用量、生产完成与 QC 状态，点击「同步排程」只读刷新
2计算剩余可用量：剩余量 = 原始可用量 − max(已排计划量, SAP 出库量) − SAP 销毁量（结果小于 0 按 0 处理）
可排归入「可排」页签，参加自动预排与上架
条件：排程状态可用 且 QC 早于最晚 QC 节点 且 剩余量 > 0
默认排序：同客户 → 同目的地 → 同 SKU → 剩余量降序
分支可排判定：排程可用 & 且 QC 满足 且 剩余量 > 0？
不可排归入「不可排」页签并展示原因，不参加自动预排
排程不可用 / QC 未满足 / 剩余量为 0
保留在列表中，不允许静默排除
3多条件筛选与浏览：产品编码多选（可搜索）＋ 生产月份 ＋ 排程状态；13 列表格支持排序、分页与横向滚动
整柜点「整柜」：按 SKU + 客户 + 目的地分组归集，给出建议货柜数与装载率
容量取 SKU 主数据继承的柜型 CBM 上限
归集为建议，需 SCM 确认后才生成货柜
分支批次操作类型：整柜归集 / 人工拆批 / 同步排程？
拆批选中单个可排批次 → 输入拆出箱数 → 确认拆分
整箱为最小单位；拆出量回池，状态「可排·人工拆批」
沿用原 SAP 批号，以拆分标识 + 序号追溯；总分配量守恒
4上架校验（硬阻断）：不同客户 → 「不同客户，不能放置统一货柜」；不同目的地 → 拆为两个货柜；操作点直接阻断，不生成后续混装预警
5对账与预警生成：SAP 销毁或库存差异影响已排批次时生成「批次不足 / SAP 对账差异」预警；QC 未满足生成 QC 类预警
6联动与留痕：刷新批次状态、受影响货柜 CBM、达成率与预警；拆批与同步动作写入操作日志；预警只提示与留痕
铁律：批次状态以排程同步为准，人工只拆批不直改数量。剩余可用量唯一口径为「原始可用量 − max(已排计划量, SAP 出库量) − SAP 销毁量」；预警不自动取消货柜、不改写数量，需要阻断的规则在上架 / 拆批 / 保存等操作点直接阻断。
处理步骤 分支 / 判定 不可排 / 阻断 闭环 / 留痕
