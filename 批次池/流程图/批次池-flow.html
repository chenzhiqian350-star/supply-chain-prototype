批次池 · 端到端业务流程

供应链协同平台 · 装柜计划模块 M04｜从批次同步到剩余量计算、SAP 状态判定、整柜归集与预警生成的待分配闭环（批次状态统一由 SAP 状态表征）

1批次数据同步：从排程系统与 SAP 拉取批次号、原始可用量、生产完成与 QC 状态，点击「同步排程」只读刷新
2计算剩余可用量：剩余量 = 原始可用量 − max(已排计划量, SAP 出库量) − SAP 销毁量（结果小于 0 按 0 处理）
非限制SAP 状态为「非限制」：可参加自动预排与上架
条件：SAP 状态非限制 且 QC 早于最晚 QC 节点 且 剩余量 > 0
默认排序：SAP 非限制优先 → 同客户 → 同目的地 → 同 SKU → 剩余量降序
分支SAP 状态判定（批次表唯一状态类字段）：非限制 / 冻结？
冻结SAP 状态「冻结」：标注红色但仍保留列表展示，行内展示不可排原因，不参加自动预排
QC 未满足 / 剩余量为 0 等异常同样保留在列表中并展示原因
不允许静默排除；已取消「可排 / 不可排」独立状态列与页签
3多条件筛选与浏览：产品编码多选（可搜索）＋ 生产月份 ＋ SAP 状态；13 列表格支持排序、分页与横向滚动
整柜点「整柜」：按 SKU + 客户 + 目的地分组归集，给出建议货柜数与装载率
容量按 SKU × 柜型 取柜内所有 SKU 上限的 MIN
归集为建议，需 SCM 确认后才生成货柜
分支批次操作类型：整柜归集 / 同步 SAP 状态？
同步点「同步 SAP 状态」拉取 SAP 回传批次库存状态（非限制 / 冻结）并刷新列表
同步只读、不改写货柜计划；状态由非限制变冻结且已排入未执行货柜时生成预警
拆批统一在装柜视图的货柜编辑抽屉处理，本模块不再设拆批入口
4上架校验（硬阻断）：不同客户 → 「不同客户，不能放置统一货柜」；不同目的地 → 拆为两个货柜；操作点直接阻断，不生成后续混装预警
5对账与预警生成：SAP 销毁或库存差异影响已排批次时生成「批次不足 / SAP 对账差异」预警；QC 未满足生成 QC 类预警
6联动与留痕：刷新批次状态、受影响货柜 CBM、达成率与预警；同步动作写入操作日志；预警只提示与留痕
铁律：批次状态以 SAP 回传为准，人工只同步不直改数量。剩余可用量唯一口径为「原始可用量 − max(已排计划量, SAP 出库量) − SAP 销毁量」；预警不自动取消货柜、不改写数量，需要阻断的规则在上架 / 保存等操作点直接阻断。
处理步骤 分支 / 判定 冻结 / 阻断 闭环 / 留痕
