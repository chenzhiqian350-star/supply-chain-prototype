# 沟通记录 · 批次池

## 需求确认（已确认决策）
- **剩余可用量唯一口径**：`剩余量 = 原始可用量 − max(已排计划量, SAP 出库量) − SAP 销毁量`；结果小于 0 按 0 处理并触发 SAP 对账差异预警。
  - 已排计划量与 SAP 出库量取 **max** 而非相加：发运后两者是同一批货的两种视角（计划分配 vs 实际出库），相加会重复扣减。
  - 守恒：`剩余可用量 + 已排计划量 + SAP 销毁量 = 原始可用量`（当已排计划量 ≥ SAP 出库量时成立）。
- **可排判定**：同时满足「排程状态可用 且 QC 早于最晚 QC 节点 且 剩余量 > 0」；任一不满足归入「不可排」页签，**必须展示原因、不静默排除**。
- **人工拆批**：仅「可排」状态批次可拆，单 SKU 单批次；整箱为最小单位；拆出量回池、状态「可排·人工拆批」；**沿用原 SAP 批号**，以拆分标识 + 序号追溯；总分配量守恒。
- **整柜归集**：按 SKU + 客户 + 目的地分组，容量按 SKU × 柜型 取柜内所有 SKU 上限的 MIN；输出为建议，需 SCM 确认后才生成货柜；不同客户、不同目的地不合并归集。
- **同步排程**：只读拉取最新批次数据，刷新状态与剩余量，**不改写货柜计划**。
- **上架硬阻断**：不同客户提示「不同客户，不能放置统一货柜」；不同目的地提示拆为两个货柜；在操作点直接阻断，不生成后续混装预警。
- **风险不自动改写**：SAP 销毁或库存差异影响已排批次时生成「批次不足 / SAP 对账差异」预警，只提示与留痕。

## 口径修正记录
- 统一 PRD §8 的批次可用量口径为 `原始可用量 − max(已排计划量, SAP 出库量) − SAP 销毁量`；原型 helpDocs（M04）中「剩余量 = 原始可用量 − 已排量，并受 SAP 出库和销毁校正」表述较模糊，**本 PRD 以 §8 公式为唯一口径**并在专章补充 5 个数值算例用于对账复算。

- **表格列调整**：移除「目的地」「排程状态」两列。
