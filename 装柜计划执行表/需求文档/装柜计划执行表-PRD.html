需求背景

装柜计划执行表是仓库按日执行装柜计划的在线表单，用于替代线下 Excel 计划表。此前仓库拿到的是一份静态 Excel，计划发生调整后无法感知，且实际柜号、封条号靠线下记录后回传，形成信息断层。

本模块的定位是执行层：仓库只需看清「今天装哪些柜、装什么、装多少」，并把实际执行信息（柜号、封条号）就地补录。计划数据本身由 SCM 在排程视图维护，执行表只读展示，不提供计划编辑能力。与排程视图的边界是：排程视图负责「计划怎么定」，执行表负责「今天怎么执行」。

需求目标

  • 提供按装柜日筛选的执行表，支持固定表头、横向滚动、在线预览与导出（不提供打印）。
  • 12 列覆盖仓库执行所需信息：货柜编号、客户、目的地、运输方式、计划时段、箱数、CBM、预计 T0、柜号、封条号、状态、计划有更新。
  • 已取消货柜不在执行表中展示——避免仓库按已作废计划执行。
  • 仓库仅维护柜号与封条号；SKU、批次、数量、计划日期一律只读。
  • 计划发生变更时以「计划有更新」列提示：24 小时内高亮，此后转灰，条目永久保留并可悬浮查看全量更新时间。
  • 执行日后仍未匹配 SAP 出库时显示 SAP 对账差异预警；CBM 超限进入执行时显示高优先级对账风险。
  • CBM 列展示「当前装载量 / 单柜上限（利用率）」，上限取该柜型的单柜容量，与排程视图容量口径一致；超过单柜上限标红、利用率不高于 85% 标黄，供仓库在装柜前一眼判断是否超装。
  • 装柜日筛选默认显示当天，方便仓库人员一进来即可处理当日装柜；当天无排柜计划时自动回落到最近一个有排柜计划的日期；同时提供「全部日期」选项，用于跨日总览当日全部在排柜货柜。
  • 执行表可随时在线预览与下载，不依赖人工确认动作。

详细方案

一级模块二级功能原型描述
装柜计划执行表 装柜日筛选与可见状态

【页面元素】顶部装柜日筛选（日期选择器，默认当天；选项为「全部日期」+ 各排柜日）；右侧两个状态说明标签：「显示计划中 / 执行中 / 已完成」与「已取消货柜不可见」。

【交互说明】切换装柜日 → 表格按该日刷新；标签为常驻说明，不作交互。

【功能逻辑】展示范围 = 所选装柜日下、生命周期状态为计划中 / 执行中 / 已完成的货柜；已取消货柜一律过滤不展示。页面加载时装柜日默认取当天；若当天不在可选的排柜日期范围内（如周末或节假日无排柜），则自动回落到最近一个不早于当天的有排柜计划的日期，便于仓库打开页面即看到待处理计划。选中「全部日期」时展示全部在排柜的合格货柜（不受日期限制）；用户显式选择过的日期（含「全部日期」）在后续重渲染中保持不被默认值覆盖。

【数据与内容规则】装柜日以货柜计划的计划装柜日为准；跨日货柜按计划装柜日归属单日。
执行表（12 列）

【页面元素】12 列：货柜编号、客户、目的地、运输方式、计划时段、箱数、CBM、预计 T0、柜号、封条号、状态、计划有更新。表头固定不换行，内容区横向滚动。

【交互说明】点击货柜编号 → 进入货柜详情查看完整明细；列宽自适应内容，窄屏下横向滚动不重叠。

【功能逻辑】箱数与 CBM 为装柜明细的实时汇总；CBM 以「当前装载量 / 单柜上限（利用率）」对比展示，单柜上限取该柜型容量，超过上限整格标红、利用率不高于 85% 标黄；状态列取货柜生命周期状态（计划中 / 执行中 / 已完成），与货柜内批次的 SAP 状态为两套独立口径。

【数据与内容规则】客户列展示简称（去除「股份有限公司 / 有限公司 / 有限责任公司 / 集团公司 / 公司」后缀）；CBM 展示批次合计值与单柜上限的对比，数值保留 2 位小数、利用率保留 1 位小数。
柜号 / 封条号补录

【页面元素】柜号、封条号单元格为就地输入框；未补录时显示「待补录」占位灰字。

【交互说明】点击单元格 → 就地编辑 → 失焦或回车即保存并写入操作日志；无权限角色点击提示「当前角色无权维护该执行字段」。

【功能逻辑】仓库仅维护柜号与封条号；SKU、批次、数量、计划日期一律只读，不提供任何编辑入口。

【前置条件与权限】柜号：SCM / SCM 主管 / 仓库可补录；封条号：仓库为主责，SCM / SCM 主管亦可补录。已取消货柜不展示，故无编辑场景。
计划有更新提示

【页面元素】「计划有更新」列展示该货柜计划内容的最近一次更新时间与相对时间（如「2 小时前」）。

【交互说明】24 小时内的更新以高亮样式展示，超过 24 小时后转为灰色；条目永久保留，鼠标悬浮可查看该货柜的全量更新时间列表。

【功能逻辑】每次计划内容变更（日期、批次、上下架、拆批等）刷新该货柜的更新时间；无变更记录的货柜显示「—」。

【文案规范】「计划有更新」为统一列名；悬浮面板标题为「更新时间记录」。
SAP 对账差异与 CBM 风险

【功能逻辑】执行日之后仍未匹配到 SAP 出库的货柜，在状态列或独立标识位显示 SAP 对账差异预警；CBM 超限仍进入执行的货柜显示实际装柜高优先级对账风险。

【边界说明】上述标识只提示，不阻断执行表的查看与补录；风险的处理在预警中心完成。

【前置条件与权限】对账差异由 SAP 出库回传结果驱动；未回传期间显示等待状态。
导出

【页面元素】页面右上角「导出」按钮（原「打印」按钮已移除）。

【交互说明】点「导出」→ 下载当日执行表 CSV / Excel，文件名格式为「装柜计划执行表-YYYYMMDD.csv」（12 列中文表头，其中 CBM 列以「装载量 / 上限 (利用率)」文本导出，带 BOM 以兼容 Excel 中文）。

【功能逻辑】导出范围为当前筛选装柜日下的全部可见货柜（已取消货柜不包含）；导出动作写入操作日志留痕。

【边界说明】执行表可随时在线预览与下载，系统不设人工确认环节（原「发布执行表快照」功能已取消）；不提供打印，如需纸质留档请导出后在本地打印。
