# 沟通记录 · 装柜计划执行表

## 需求确认（已确认决策）
- 定位为**仓库按日执行的执行层**，替代线下 Excel 计划表；计划数据一律只读，工厂执行层只补录实际信息。
- **已取消货柜不在执行表展示**（提升为需求目标第 3 条）：避免仓库按已作废计划执行；页面常驻标签「已取消货柜不可见」。
- **14 列**：货柜编号、客户、目的地、运输方式、计划时段、SKU 批次数、箱数、CBM、QC 摘要、预计 T0、柜号、封条号、状态、计划有更新；表头固定、横向滚动。
- **字段可编辑性**：仓库仅维护柜号与封条号；SKU、批次、数量、计划日期一律只读，不提供编辑入口。柜号 SCM / SCM 主管 / 仓库可补录（发运后仍可）；封条号仓库为主责。
- **「计划有更新」时效**：24 小时内高亮、之后转灰、**永久保留**；悬浮查看该货柜全量更新时间列表。
- **风险只提示不阻断**：执行日后仍未匹配 SAP 出库 → 显示「SAP 对账差异」预警；CBM 超限进入执行 → 显示高优先级对账风险；处理在预警中心完成。
- **导出与打印**：随时在线预览、下载、打印，不依赖人工确认动作；CSV 文件名「装柜计划执行表-YYYYMMDD.csv」（14 列中文表头，带 BOM）。
- **边界**：本 PRD 只描述执行表本身（筛选、列、补录、导出、对账）；货柜计划内容的编辑、状态机与权限矩阵已在《排程视图》PRD V1.1 覆盖，本文只做交叉提及，不重复展开。
