# 沟通记录 · 装柜工作台

## 需求确认（已确认决策）
- 工作台定位为 **SCM 每日入口的判断层**：先确认数据是否可用，再处理最高优先级风险并直达货柜 / SKU / 批次。
- **三筛选联动**：需求月份（N～N+6）＋ 客户 ＋ 目的地；任一变化即重新汇总当前启用预测版本、批次池与货柜计划。
- **数据准备状态**四类：需求版本、排程批次、QC、SAP；每项展示最近同步时间与异常，并提供跳转入口。
- **四张核心指标卡**：需求预测量、预计装柜量、达成率（预计装柜量 / 需求预测量）、CBM 风险柜数。
- **待处理清单固定优先级**：当日执行风险 > CBM 超限 > QC/批次不足 > SAP 差异 > T0 延期 > 数据缺失。
- **预排两种口径**：生成预排按 SKU + 客户 + 目的地的需求缺口生成，仅使用可排且 QC 可满足的批次；重新预排为**保护式**，既有货柜不被改写，仅补新增需求或已有缺口。
- **异常保留原则**：缺少启用预测版本、主数据缺失、QC 风险、批次不足一律保留预警，**不自动阻断既有计划、不静默排除**。
- **边界**：计划列表只作浏览与跳转，不在此页直接编辑计划内容；数量、批次、货柜调整在排程视图 / 货柜编辑抽屉完成。
